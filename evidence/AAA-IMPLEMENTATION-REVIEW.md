# Native implementation review — 16 November 2026

This is implementation evidence for the bounded proofs in the overhaul plan. It does not mark the entire website, its 204-route migration, or AAA visual quality complete.

## Actual work

- Three native Q42 publications: the retained 17,949-record Schema.org graph, 153 records describing public reference data and authored policy scenarios, and 402 records explaining sixteen ecosystem modules. Query fixtures execute the existing QualiaDB compiler and VM; they are not substituted query algorithms.
- Native Rust/WASM laboratory controls for dataset inspection, editable graph patterns, decoded result tables and export, rights withdrawal/expiry, Earth coordinates and analytical Sun/Moon calculations, checks, and cancellable repeated-query measurements. The browser loads only generated WASM bindings.
- Actual Canberra reference terrain acquired through the ecosystem DEM adapter; source PNGs, source bundle, attribution, georeferencing and native production receipts retained. A separate 1:30 model has no vertical exaggeration. It is independent of the camping journey.
- Corrected two real geospatial defects: Mercator tile selection and downward-facing DEM triangle winding. Native regressions exercise the corrected source.
- Native Synth habitat texture atlas, normal and ORM maps, authored UVs and preserved material transforms. This terrain is explicitly artwork, not a measured land-cover map.
- Native ecology families and evaluated placements: trees, bedded rocks, curved grass, shrubs and litter. Every submitted surface uses actual native production, retained inputs and review images.
- Native material identity reconciliation fixes collisions between independently produced assets. It preserves every non-material section byte for byte, including geometry, UVs, provenance and policy. Corruption, collision and idempotence checks pass.

## Evidence and remaining gates

The data handoff is [aaa-data/handoff.json](aaa-data/handoff.json), the data validation is [aaa-data/final-validation.json](aaa-data/final-validation.json), and the art review is [aaa-art/NATIVE-ENVIRONMENT-REVIEW.md](aaa-art/NATIVE-ENVIRONMENT-REVIEW.md). Browser run receipts are stored separately for the assembled world, laboratory and measured terrain.

The bounded laboratory browser run in `aaa-browser/results.json` passed the actual query, permission withdrawal, eleven checks, ten warmups, thirty measured runs and cancellation. It also checked sixteen module and human-purpose results, the served runtime binary identity, field gain changing actual pixels while preserving the underlying 13,824 cells, field export, all four observer paths and mobile layout. That run used WASM SHA-256 `6f508880c0b696c4a92d5fe91410bd137f8aec093c4c9ab6d6102c1b4698f2cf`. Later runtime builds require their own qualification. No competitor or production performance claim follows from these measurements.

The assembled art has received native browser review, and visual acceptance remains withheld: canopy repetition, ground-cover density, campsite materials and atmosphere need further work. Standalone PNGs, asset counts and successful admission do not establish acceptable composition. Native per-prototype streams are now implemented across forward rendering, AO, shadows and picking. The complete 367 ecological placements remain; native geometry payload falls from 262,515,624 to 100,647,704 bytes, retaining 2,443,920 expanded triangles. This is a payload reduction, not a frame-rate claim. Browser qualification, automatic LOD and streaming remain open.

Actual frame measurements exposed severe rendering lag: the full baked scene measured roughly one second per frame while native tick CPU/submission time was around two milliseconds. GPU pass timing is being added to distinguish render costs; CPU submission timings alone cannot identify the expensive GPU pass. The empty-page control was fast. The earlier comparison was not a controlled Three.js benchmark.

The native production instrument now has four real Vibe recipes (boundary artwork, lettering, sound and PBR maps). The live same-origin Synth service passed all four recipes, repeated deterministic HMC production, changed resource bytes, SHA/length verification, 150-morphism inventory, private-path refusal, ranged WASM delivery and isolation-header checks. Evidence is `aaa-production-http/results.json`; all eighteen native server tests pass. Browser interaction and visual qualification are still separate requirements. No saved fixture substitutes for a new production request.

The renewed ATL installation succeeded and enabled Etalon's full all-feature test build. That full run was deliberately interrupted after 273 completed cases (271 passed, one failed, one aborted) to fix two discovered issues. The OpenGL indefinite-wait truncation has a candidate correction with ten unit tests and a successful GL-only compile. The Vulkan abort was reproduced in the benchmark and removed by correcting its unbound descriptor access and concurrent writes; all seven revised sub-benchmarks pass with unchanged provider libraries. These are separate from the BrowserWebGPU frame-rate investigation. The combined Etalon candidate still needs focused GPU verification, publication, a new pin and the full suite; no full-suite pass is claimed.

The old datasets, demo routes and benchmark records remain preserved. They are not labelled migrated merely because their files remain available. The full demonstration/module migration and the remaining realm artwork stay open in the master plan.
