# Complete Webizen overhaul planning pack

Start with [MASTER-PLAN.md](MASTER-PLAN.md).

This pack treats the current preview as an engineering prototype that failed visual acceptance. It plans the complete native website and data/demo migration; it does not claim that implementation is finished.

The master A00–A27 IDs are the programme work packages. The 43-node milestone graph controls execution: bounded proof work precedes A21 approval; full expansion cannot start before that approval. Domain-specific IDs in companion specifications are subordinate contracts assigned to those owners. If a technical proposal conflicts with a user requirement, the requirement controls; record and resolve the conflict before implementation.

**Completion rule:** the underlying data and actual capability demonstrations operate inside the new environment, with native controls, inspectable results, provenance, export and an accessible equivalent. A legacy page link, iframe, screenshot, cinematic or retained file cannot satisfy that rule.

**Implementation is now authorised and underway.** [Implementation state](IMPLEMENTATION-STATE.json) records the active proof work. Actual native data acquisition, asset production and in-world instruments are being implemented and reviewed. Public deployment and production visual acceptance have not occurred; A21 remains open.
