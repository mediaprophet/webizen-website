## Prioritised dataset map

Licence/access entries are what the local register documents. Verify the specific release and payload before acquisition or redistribution.

| World purpose | Sources identified locally | Documented access / rights constraints | Concrete integration |
|---|---|---|---|
| Real ground form | ELVIS; NSW Spatial Services DEM/LiDAR; GA SRTM DEM-H/DEM-S; Digital Atlas discovery | Register records CC-BY 4.0 for named GA/NSW products; GeoTIFF/COG and LAS/LAZ/COPC are distinct payloads. Preserve actual CRS, vertical datum, epoch, resolution and attribution. | One public bounded terrain window first. Retain raster evidence and produce native terrain with explicit local-metre transform. |
| Vegetation structure | Published canopy-height/DSM products via TERN/DEA or product catalogues | Register groups multiple products under broad “CC-BY/Open” wording; that is insufficient product-specific permission. Pin actual producer, release, licence and measurement method. | Use accepted canopy heights to constrain crown scale; never infer species identity from height alone. |
| Vegetation and bioregion context | DCCEEW IBRA, NVIS, CAPAD; TERN AusPlots/EcoPlots | Register says verify per DCCEEW product; TERN licence is product-specific. Context polygons are not precise tree surveys. | Locality profile sets vegetation families and placement constraints; label published spatial scale. |
| Water and drainage | Geofabric; GA hydrography; public state hydrology | Register records CC-BY 4.0 for Geofabric; API/endpoints still need checking. A mapped stream is not a current water-level observation. | Bind source river geometry to native corridors/water; separate observed geography from authored flow/appearance. |
| Soil and geology | SLGA/CSIRO/TERN; NSW geology WFS; SEED discovery | SLGA recorded CC-BY 4.0; other actual dataset terms must be retained. Depth layers and units matter. | Evidence layer for soil colour/strata, with modelling assumptions separate from measured values. |
| Plant identifiers | auNSL/APC/APNI; Flora of Australia; AVH specimen records via ALA | NSL reuse terms explicitly unresolved in register; Flora profile bulk rights also an open question. AVH terms vary per record/image. | Preserve qualified source identifiers and name/concept versions; do not treat GBIF numeric keys as APC identifiers or name equality as taxonomic equivalence. |
| Plant occurrences | ALA; GBIF; NSW BioNet | ALA/GBIF record-level CC0/CC-BY/CC-BY-NC; protected ALA APIs require JWT. BioNet documented token/tier access. Preserve download DOI, query, date and source generalisation. | Public source-filtered occurrence subset for a declared locality; no sensitive coordinates and no claim that an occurrence is current individual-tree location. |
| Botanical dimensions and traits | AusTraits release + dictionary; TERN surveys; descriptive Flora profiles | AusTraits recorded CC-BY 4.0, with dataset authors and original sources credited. Pin a release DOI; endpoint registry's specific Zenodo record is not automatically the current release. | QUDT units, trait definition, measured/estimated status, range, source and uncertainty feed species corpus and native geometry parameters. |
| Botanical reference imagery / sound | ALA/AVH images; TERN EcoImages/EcoAcoustics; iNaturalist; Commons | Per-image/record licences and credits, including NC/SA restrictions; site-level permission is insufficient. | Reviewed reference resources or accepted textures/audio with their own manifest entries, not undocumented copying. |
| Tracks and public place relations | Public OSM extracts/services; Gazetteer; Wikidata | Register lists ODbL for OSM, separate provenance; CC0 for Wikidata; dataset-specific attribution for Gazetteer. | Small public geometry/relationship subset. A mapped gate/track/campsite does not establish current access or availability. |

FABDEM is explicitly recorded as CC-BY-NC-SA / requiring commercial-versus-commons review. Do not silently include it in a permissive website pack. A local `SocialPermissiveCommons` field does not replace upstream source terms.

The register requires preserving source sensitivity, including ALA/BioNet public/restricted distinctions and coarse threatened-species products. Community seasonal calendars are described as co-owned, requiring negotiation/TK labels; restricted heritage and oral-history detail is not public scenery input. Country is a relation, not a cadastral parcel. None of these sources authorises adding precise personal camping history to the public world.

## Bounded implementation handoff

1. **GIS/source agent:** choose one public locality independently of private travel records; register one terrain release and one IBRA/NVIS context release. Verify current official endpoints and exact payload rights, then fetch only the agreed small extent through existing native interfaces. Deliver immutable snapshot hashes, request/coverage, CRS/datum/units/nodata and attribution.
2. **Botany/evidence agent:** select a small locality-supported species set; resolve source taxon identifiers, public occurrence evidence and versioned traits. Produce a source/assertion/conflict/gap corpus and clear media references. Do not transplant the arid ghost-gum example into an unrelated woodland merely because its local asset exists.
3. **Native production agent:** map accepted data into authored native terrain and species geometry. Preserve originals and separate measured, inferred and artistic layers. Inspect front/side/quarter native previews and the assembled scene; retain real Synth recipes, HMC replay and `.10d`/`.m64` receipts.
4. **Integrator/reviewer:** expose Q42-backed “about this landscape/species” evidence in the existing Rust/WASM world, with source/scale/time labels and readable alternatives. Verify marker-to-entity selection, correct units, bounded memory and no accidental precise/sensitive coordinates. Keep demo/benchmark preservation gates from `NATIVE-ARCHITECTURE-CORRECTION.md` intact.

Acceptance is a correctly sourced, visually reviewed native scene slice plus inspectable evidence. This document does not certify the local authored catalogues, a complete species package, real-world site reconstruction, current external service availability or permission for every listed dataset.
