# Migration gate

`data/demos.json` accounts for all 202 inventoried HTML source routes. It is not a claim that all 202 are runnable demonstrations. No route can disappear without a documented disposition, destination/redirect decision, owner and fragment strategy.

Next: map each genuine demo to capabilities and an effective runtime profile; assign owners; run it; record defects and evidence; author its new public and technical explanation; integrate it into an appropriate natural/social/cultural environment and the direct demo index.

The imported inventory deliberately leaves unknown module ownership and runtime qualification empty. CI should reject promotion of incomplete records, not fabricate those facts. Normative identifiers and historical records preserve their meaning and attribution.
